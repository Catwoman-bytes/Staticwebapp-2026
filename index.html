Azure & GitHub Architectuur

Deze website is het levende bewijs van een moderne DevOps workflow. In plaats van handmatig bestanden te FTP'en, maakt dit project gebruik van een moderne cloud-architectuur:

  • Source Control: Code staat veilig op GitHub.
  • Automatisering: GitHub Actions bouwt de app bij elke push.
  • Hosting: Azure Static Web Apps serveert de HTML/CSS met ingebouwde SSL-certificaten.
